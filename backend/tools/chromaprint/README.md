# Bundled Chromaprint Tool

`fpcalc.exe` is bundled so acoustic fingerprinting works out of the box on Windows installs.

- Upstream: <https://github.com/acoustid/chromaprint>
- Release source: <https://github.com/acoustid/chromaprint/releases>
- Version checked in: `fpcalc version 1.6.0`
