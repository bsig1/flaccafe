# Bundled CD Ripping Tools

This folder contains the small Windows cdrtools bundle used for CD extraction and CD-Text support.

- Primary executable used by FLAC Cafe: `cdda2wav.exe`
- Bundle source: <https://sourceforge.net/projects/cdrtools/files/alpha/win32/cdrtools-1.11a04-win32-bin.zip/download>

The files are kept together because the Windows build expects its companion executables/DLLs nearby. See `THIRD_PARTY_NOTICES.md` at the repository root for the redistribution note.
