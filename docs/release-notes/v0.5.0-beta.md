- Added broader library views: artists, albums with completion browsing, playlists, audiobooks, podcasts, web radio, sources, CD, history stats, and file management.
- Added native Rust playback experiments alongside WebView playback, including CPAL/WASAPI shared output, Symphonia decoding, crossfade support, diagnostics, and visualizer frames.
- Added a more complete Now Playing/Queue experience with lyrics fetching/editing, synced lyric support, queue editing, party mode, visualizers, and a sleeker mini player.
- Added MusicBrainz auto-tagging, AcoustID/Chromaprint fingerprint matching, CLAP genre tag previews, ReplayGain-style volume tags, tag backups, regex cleanup, CSV metadata import/export, and database-to-file tag sync.
- Added source-folder management and background folder watching with pending-change review.
- Added podcast subscriptions/downloads, audiobook progress/bookmarks/chapters, web radio bookmarks, and scrobbling setup for user-supplied ListenBrainz/Last.fm credentials.
- Added CD drive detection, selected-track live CD playback through the main player, MusicBrainz disc lookup, and FLAC/MP3/WAV ripping workflows.
- Added bundled Chromaprint and Windows CD helper tools, plus third-party notices for redistributed binaries.
- Added MSI packaging improvements, release-note generation, and installer app-data cleanup support.
