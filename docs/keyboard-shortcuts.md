# Keyboard Shortcuts

FLAC Cafe ships with customizable shortcuts. Open Settings, expand **Keyboard Shortcuts**, click any shortcut, then press the replacement keys. Escape cancels capture.

## Default Page Shortcuts

- `Ctrl + 1`: Library
- `Ctrl + 2`: Analysis
- `Ctrl + 3`: Now Playing
- `Ctrl + 4`: Artist
- `Ctrl + 5`: History
- `Ctrl + 6`: AutoDJ
- `Ctrl + 7`: File Management
- `Ctrl + 8`: Settings

## Default Playback Shortcuts

- `Space`: Play or pause
- `Alt + ,`: Previous track
- `Alt + .`: Next track
- `Alt + ArrowLeft`: Seek backward
- `Alt + ArrowRight`: Seek forward
- `Alt + ArrowDown`: Volume down
- `Alt + ArrowUp`: Volume up
- `Alt + M`: Mute

## Library Selection

- `Delete`: remove the selected track or selected tracks from the library.
- `Ctrl + E`: edit selected track metadata when a selection exists.
- `Shift + click`: select a range of tracks.
- `Ctrl + click`: add or remove individual tracks from the current selection.

## Notes

- Settings warns when imported shortcut presets collide.
- Media keys are handled separately through Windows media controls when available.
- Local audio controls can use these shortcuts even when the mouse is not over the player bar.
